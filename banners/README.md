# 横幅素材

把喜欢的图片放进 `banners/originals/`，提交并推送到 GitHub 后，横幅工作流会自动重新生成。支持 PNG、JPG、JPEG、WebP；不同图片请使用不同的文件名（不含扩展名也不能重复）。

## 切换方式

`banners/config.json` 中的 `selection` 控制默认选择：

- `"random"`（默认）：每次生成时随机打乱所有图片，每 5 秒切换一张；一组中每张图恰好出现一次，整组循环播放，首张也参与随机。系统减少动态效果时仍显示 `default` 指定的静态图片。
- `"slideshow"`：在页面内每 5 秒自动切换一张，循环播放。先显示 `default` 指定的图片，再遵循 `order` 数组中的顺序。
- `"auto"`：按 UTC 日期每天选择一张静态图片，文件名排序决定顺序。同一天重复运行会选择同一张。
- `"default"`：固定使用 `default` 指定的图片，初始为 `60_i09.png`。
- `"47_i13_1.png"` 等原始文件名：固定使用指定图片。

页面轮播使用支持完整透明度的 APNG 图片，不依赖 JavaScript，也没有点击切换按钮。启用系统「减少动态效果」时，主页使用静态横幅。可修改 `interval_ms` 调整每张图的停留时间，`5000` 表示 5 秒。

APNG 的播放顺序固定在文件里，因此随机模式是在生成时洗牌；同一文件每轮按相同顺序播放。每日自动更新、相关文件推送或手动运行工作流时会重新洗牌，刷新网页不会单独重新洗牌。

### 切换动画

默认采用 0.5 秒交叉淡入淡出，包括最后一张回到第一张的过渡。每张静止显示 4.5 秒，再过渡 0.5 秒，合计仍为 5 秒一张；8 张图完整循环 40 秒。过渡保留透明底边，可融入浅色和深色页面。系统减少动态效果时仍显示静态横幅。

通过 `banners/config.json` 中的 `transition` 自定义：

```json
"transition": {
  "effect": "crossfade",
  "duration_ms": 500,
  "frames": 4
}
```

- `effect`：`"crossfade"` 为交叉淡入淡出，`"none"` 为直接切换。
- `duration_ms`：过渡时长，必须为正整数且小于 `interval_ms`；该时长已包含在每张图的总时间内。
- `frames`：过渡的中间帧数量，默认 4。增大可让过渡更细，但也会显著增加 APNG 体积；允许 1 到 60，且不能大于 `duration_ms`。

过渡帧预先写进 APNG，修改配置后需要重新生成横幅。

顺序模式的播放顺序：`60_i09` → `47_i13_1` → `61_i21` → `73_i25_1` → `73_i25_2` → `73_i25_4` → `74_i13_1` → `74_i07`。编辑 `order` 可以调整顺序；新加入但未列入数组的图片会按文件名顺序追加。已移除的文件和重复条目会自动跳过。顺序模式的第一张始终由 `default` 指定，随机模式会打乱全部图片。

手动运行 GitHub 工作流时可填写 `random`、`slideshow`、`auto`、`default` 或完整文件名；该选择会保存到配置中，后续运行也会继续使用。留空则保持当前设置。要恢复随机顺序轮播，填写 `random`；要固定播放顺序，填写 `slideshow`。

## 调整裁切

默认以原图中心裁成约 3:1。1600 × 900 的图片会生成 1600 × 534 横幅。每张静态裁切保留原始分辨率；轮播需要统一画布，新增不同尺寸的图片会按比例缩放至不超过 1600 × 534 的共同画布，不拉伸。

裁切前先查看原图内容，逐张确定构图。人物图应保留清晰可辨的面部、头部轮廓与关键姿态，给头饰和发梢留出空间，并兼顾原图的光影与留白。检查浅色、深色背景下的最终横幅，避免底部渐隐削弱人物主体。

在 `images` 中按完整文件名设置 `crop_y`（竖直位置）或 `crop_x`（水平位置）：

```json
"new-picture.jpg": { "crop_y": 0.5 }
```

- 小数 `0.0` 到 `1.0` 表示在可移动范围内的位置：`0.0` 靠上/左，`0.5` 居中，`1.0` 靠下/右。
- 整数表示从原图上方/左侧开始裁切的像素数。例如 `250` 表示距离上边缘 250 像素；`1` 则是 1 像素。
- 不写配置的新图片会自动居中裁切。已附带的八张图已单独调整位置。

`fade_start` 控制底部渐隐从横幅高度的哪个位置开始，范围为 `0.0`（含）到 `1.0`（不含），默认 `0.5`。两张新人物图分别设为 `0.75` 和 `0.68`，让头部与姿态保留更清晰的细节，同时保持底边透明。

## 本地生成

先安装 Python 和 Pillow，然后在仓库根目录运行：

```bash
python -m pip install Pillow
python scripts/build_banner.py
python scripts/build_banner.py --select random --save-selection
python scripts/build_banner.py --select slideshow --save-selection
python scripts/build_banner.py --select 60_i09.png
python scripts/build_banner.py --select 60_i09.png --save-selection
python scripts/build_banner.py --select auto --date 2026-10-07
```

每张静态横幅保存在 `assets/banners/`；当前横幅（默认是 APNG 轮播）保存在 `assets/banner.png`，供主页引用。`assets/banner-static.png` 是减少动态效果时使用的静态版本。

本地命令只有加上 `--save-selection` 才会保存选择；不加时只生成本次横幅。
